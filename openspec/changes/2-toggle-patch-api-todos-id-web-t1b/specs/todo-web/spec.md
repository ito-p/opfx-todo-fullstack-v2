## MODIFIED Requirements

### Requirement: 起動時の一覧の表示
web は起動時に `GET /api/todos` から一覧を読み、1 件以上あれば T1 のとおり、見出し「todo」・追加の form・todo の行の並びを描かなければならない(SHALL)。行は API が返した順に並べ、各行は左からチェックボックス・題名・「削除」ボタンを持たなければならない(SHALL)。`done` が `false` の行のチェックボックスは印の無い状態で描く(SHALL)。`done` が `true` の行は T1b のとおり、チェックボックスを印の付いた状態で、題名を取り消し線付きの灰色で描かなければならない(SHALL)。

#### Scenario: 起動時の一覧の行
- **WHEN** API が「牛乳を買う」「掃除する」「本を返す」の 3 件(どれも `done` が `false`)を返す状態で web を起動する
- **THEN** 画面には見出し「todo」、プレースホルダー「題名を入力」の入力欄、「追加」ボタン、その 3 件の行がこの順に描かれ、各行にチェックボックス(印なし)・題名・「削除」ボタンがある

#### Scenario: 起動時の完了の行
- **WHEN** API が「牛乳を買う」(`done` が `true`)「掃除する」「本を返す」(どちらも `done` が `false`)を返す状態で web を起動する
- **THEN** 「牛乳を買う」の行はチェックボックスに印が付き、題名が完了の見た目(取り消し線・灰色)で描かれ、ほかの 2 行は印なし・通常の題名で描かれる

## ADDED Requirements

### Requirement: 完了の切り替え
行のチェックボックスを押すと、web はその行の todo の `done` の反対の値を `PATCH /api/todos/:id` に送らなければならない(SHALL)。成功したら返った todo の `done` でその行を描き直さなければならない(SHALL): `true` なら T1b の完了の見た目、`false` なら T1 の未完了の見た目。行の位置と他の行は変えない(SHALL)。API の応答を待つ間、チェックボックスの見た目は押す前のまま変えず(SHALL)、同じ行のチェックボックスをもう一度押しても API に送ってはならない(MUST NOT)。API が失敗を返したときは行を押す前の見た目のまま残さなければならない(SHALL)。

#### Scenario: 未完了の行の完了
- **WHEN** 「牛乳を買う」「掃除する」の 2 行(どちらも未完了)が描かれた画面で「牛乳を買う」のチェックボックスを押す
- **THEN** `PATCH /api/todos/:id` にその todo の `id` と `done: true` が送られ、応答の後「牛乳を買う」の行はチェックボックスに印が付き題名が完了の見た目になり、「掃除する」の行は変わらない

#### Scenario: 完了の行の未完了
- **WHEN** 完了の「牛乳を買う」の行のチェックボックスを押す
- **THEN** `PATCH /api/todos/:id` にその todo の `id` と `done: false` が送られ、応答の後その行はチェックボックスの印が消え題名が通常の見た目に戻る

#### Scenario: 応答待ちの間の再押下
- **WHEN** 未完了の行のチェックボックスを押し、API の応答が返る前にもう一度押す
- **THEN** API に送られるのは 1 回だけで、応答が返るまでチェックボックスは印の無いまま、応答の後に完了の見た目になる

#### Scenario: 切り替えの失敗
- **WHEN** 未完了の行のチェックボックスを押し、API が status 404 を返す
- **THEN** その行はチェックボックスの印が無く題名が通常の見た目のまま残る

### Requirement: まだ動かない削除ボタン
各行の「削除」ボタンは押せる形で描くが、押しても画面の状態を変えてはならず(MUST NOT)、API を呼んではならない(MUST NOT)。

#### Scenario: 削除ボタンの無反応
- **WHEN** 行の「削除」ボタンを押す
- **THEN** 行は残ったままで、API は呼ばれない

## REMOVED Requirements

### Requirement: まだ動かないチェックボックスと削除ボタン
**Reason**: チェックボックスは「完了の切り替え」で動くようになる。削除ボタンだけが動かないまま残る。
**Migration**: チェックボックスは「完了の切り替え」、削除ボタンは「まだ動かない削除ボタン」の要求に従う。
