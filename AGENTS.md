# AGENTS.md

## Project knowledge
pnpm workspaces で web/(Vite + TypeScript の素の DOM)と server/(Hono + TypeScript + SQLite better-sqlite3)を持ち、試験は vitest。root の `pnpm test` が両方の workspace の試験、`pnpm build` が両方の build を走らせる。pnpm-lock.yaml を commit する(CI は `pnpm install --frozen-lockfile`)。CI は .github/workflows/test.yml(pnpm install / test / build)。方針ファイル(.github/workflows、.factory、AGENTS.md)は worker が触らず、必要なら人に返す。
設計の道具: 共有の Figma ファイル(key <figma-file-key>)の Screens ページが画面の正本。書き方と配置の規則は 社内の設計文書(Screens の配置と線の規則、画面ごとの specs、wireframes)を読んで、この repo の docs/design に写す(規則と画面の実値だけを書き、製品の振る舞いは書かない)。

## opfx rules (do not remove)
- One change per Issue, branch `factory/<change>`, worktree `../<repo>-wt/<change>`; a worker touches only its own worktree.
- Never edit `openspec/specs/**` directly; the source of truth changes only through `openspec archive` run by `archive.sh`.
- Never edit `.claude/commands/opsx/*` or `.claude/skills/openspec-*` (generated by OpenSpec).
- Never create approval files; human approval lives only in GitHub comments and labels.
- Reviews and rubric verdicts follow `.factory/rubric.md`; numbers (rounds, retries) come from `.factory/config.json`.
