# docs/design の規則

出所: 社内の設計文書(`refs/screens-layout.md`・`specs/*.md`・`wireframes.md`)を 2026-09-27 に読んで、この repo に要る規則だけを写した。製品の振る舞い(何を押すと何が起きるか)はここに書かず、`openspec/specs/` が正とする。ここに書くのは画面の描き方・置き方と、画面の実値だけ。

## 正本

- 画面の正本は 共有の Figma ファイル(file key `<figma-file-key>`)の **Screens** ページ(`0:1`)の canvas そのもの。本書と `screens.md`・`specs/` はその規則と写しで、食い違えば Figma が正。
- 画面の frame の中身と大きさは、画面を変える change だけが変える。配置を直すときに動かすのは位置だけ。

## 画面コード

- 画面は英大文字 1 字の群 + 番号で呼ぶ(例 `T1`)。この repo の群は `T`(todo)。
- 同じ画面の別の状態(差分)は、基準のコードに英小文字を 1 字足す(例 `T1a` = T1 の 0 件、`T1b` = T1 の完了あり)。
- frame の名前は「<コード> <画面の名前>(<状態>)」(例「T1a todo 一覧(0 件)」)。frame の中の node の名前は役割の英語の kebab-case(`add-form`・`title-input`・`todo-item`・`delete-button` など)で、実装の class 名と揃える。

## Screens ページの配置と線

- **列 = 深さ、右へ行くのが遷移か差分。** 根はページの左上(列 0・行 0、x 0・y 0)。
- **最初の子は同じ行の右隣の列。** 差分は基準の右に鎖で並べ、基準 → 差分 1 → 差分 2 → … と 1 列ずつ右へ進む。
- **2 つ目以降の子は、直前の兄弟の部分木が使った最後の行の次の行**(DFS の先行順で行を割り当てる)。ある画面からの遷移の子は、差分の鎖の後ではなく次の行以降に置く。
- **列の幅** = その列の node の最大の幅 + 64。**行の高さ** = その行の node の最大の高さ + 96。根が複数なら列 0 に縦に積む(木と木の間 192)。
- **線**: 遷移 = 黒 #171717・太さ 10・終端に矢印。差分 = 灰 #CCCCCC・太さ 10・矢印なし(同じ行の水平の線)。区別は色と矢印。
- **始点と終点は frame の辺の中央**: 同じ行は親(または前の差分)の右端の高さの中央 → 子の左端の高さの中央(高さが違えば間の中点で縦に 1 段ずらす直交の折れ線)。下の行の子へは、親の下端の幅の中央から縦に降り、子の高さの中央の y で右へ折れて子の左端に刺さる(幹は最後の子の行まで 1 本でよい)。
- **線の置き場**: ページに 1 つの群 `flow-lines`(最背面)。線の名前は「<親> -> <子> 遷移|差分」。作り直すときは群ごと削除する。
- **ページを跨ぐ遷移**は線でなく、frame の上に置く灰 #737373・12px の文字ラベル(例「→ U 設定」)。
- **画面コードを持たない補助の node**(部品、注記の文字)は、その行の右端(差分の鎖の右)へ 64 空けて寄せる。

## 検算の仕方

Figma の画面や配置を変えた後は、ページの全 node を `get_metadata` で読み戻して (1) 規則から求めた座標との不一致 0、(2) node どうしの重なり 0、(3) 全線の始点・終点が辺の中央に乗る、(4) 線の色と太さ、を確かめ、ページか frame の screenshot(`get_screenshot`)で目視する。

## 画面ごとの実値の書き方(`specs/`)

- 1 つの画面(とその差分)につき 1 つの文書 `specs/<コード>[-<コード>…].md`。頭に「出所」: file key・frame の node id・大きさ・読んだ道具(MCP `get_design_context` / `get_metadata`)・読んだ日。
- 本文は **縦の並び**(領域 / 高さ / 内側 / 中身の表)→ 各領域の部品の実値(寸法・内側・gap・角丸・枠・色・文字の大きさと太さ・文言)→ 差分の画面は基準との違いだけ。
- 値は Figma から読み戻した数をそのまま書く(推定や丸めをしない)。Figma を変えたら同じ change で書き直す。
- 実装が frame と意図して違う所は「実装への含意」に理由と一緒に書く。
